Webseiten-Rendering

Für rein per JavaScript aufgebaute Hotelseiten kann optional ein echter Browser (Playwright, kostenlos, lokal) genutzt werden. Installation: pip install playwright && playwright install chromium. Ohne Playwright wird immer statisch geladen.

E-Mail-Versand (SMTP)

Für den Versand dein eigenes Postfach nutzen (z. B. Gmail mit App-Passwort). Kostenlos, keine externen Dienste.

E-Mail-Abruf (IMAP)

Zum automatischen Abrufen eingehender Angebote aus deinem Postfach. Bei Gmail dasselbe App-Passwort wie beim Versand nutzen.
